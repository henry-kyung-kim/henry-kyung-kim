일정 알림

일정 등록 시 설정한 시점에 알림을 받아요. 홈 화면에 추가한 뒤 여기서 알림을 켜면, 앱을 닫아둔 상태에서도 알림이 도착해요. (iPhone은 iOS 16.4 이상, 반드시 홈 화면에 추가한 뒤 그 아이콘으로 열어서 켜야 해요)

알림 상태 확인 중…

지금은 Safari 브라우저 탭이에요. 공유 버튼 → "홈 화면에 추가"로 설치한 뒤, 그 아이콘으로 다시 열어서 알림을 켜주세요.

가져오기 · 백업

캘린더 가져오기 (.ics) — iPhone·구글 캘린더

iPhone: 캘린더 앱에서 캘린더 공유 → ".ics 파일로 보내기"로 저장
구글 캘린더: PC에서 calendar.google.com → 설정 ⚙ → "가져오기/내보내기" → 내보내기 → 받은 zip의 압축을 풀면 .ics 파일이 나와요
저장한 .ics 파일을 아래에서 선택하면 일정이 날짜별로 들어옵니다. (반복 일정은 첫 회차만 가져와요)

데이터 백업 / 복원

데이터는 서버에 저장되어 어느 기기에서든 같은 계정으로 보입니다. 그래도 만일에 대비해 JSON 백업을 받아둘 수 있어요.
